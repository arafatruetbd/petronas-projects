#### E-Invoice Project
- **Role**: Full Stack Developer  
- **Duration**: January 2024 – December 2024  
- **Project Link**: [https://einvoice.petronas.com/login](https://einvoice.petronas.com/login)  
- **Description**:  
  Integrated Malaysia’s government e-Invoice system into PETRONAS’ internal platform to automate invoice processing and securely send data to the tax authority (IRBM). Focused on building fast APIs, user access control, and a system that supports multiple business units.  
- **Responsibilities**:  
  - Optimized database interactions by implementing Drizzle ORM with secure AES-256 encryption/decryption to protect sensitive data at rest.  
  - Developed UI Dashboard and OPU Management Page using Next UI and Tailwind CSS from Figma designs, ensuring encrypted communication between client and server for data security.  
  - Architected role-based access control (RBAC) system for fine-grained permission checks and advanced search functionality, with encrypted storage of sensitive credentials and tokens.  
  - Integrated AWS S3 for secure file uploads, implementing encryption in transit and at rest using server-side encryption and custom encryption keys.  
  - Mentored junior developers within Agile methodologies, emphasizing best practices in cryptographic security across full-stack applications.  
  - Innovated multi-tenancy feature for scalable architecture, using tenant-specific encrypted data partitions to guarantee data isolation and privacy.  
  - Created reusable custom React hooks for pagination and automatic logout, integrating encryption of sensitive query parameters and secure token storage for enhanced UI responsiveness and security.  
  - Built an Autocomplete React component integrated with Microsoft Graph API, implementing encrypted storage for cached sensitive data and secure API communications.  
  - Implemented Excel export functionality with optional encryption of generated spreadsheets to protect sensitive reports.  
  - Developed server-side email services using Microsoft Graph API, incorporating encryption for sensitive email data and attachments along with role-based dynamic content.  
  - Achieved 75% code coverage on SonarCloud by writing comprehensive unit tests using Jest.  
- **Technologies**:  
  Next.js, React, TypeScript, Drizzle ORM, Tailwind CSS, Next UI, AWS S3, AWS Lambda, AES-256 Encryption, Microsoft Graph API, MSAL, Node.js, PostgreSQL, GraphQL, NestJS, SonarCloud
